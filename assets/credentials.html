    Access protection
    Your administrator login is separate from development access. Secret values are never shown in this register.
    1
    Values in Infisical
    Each application has an Infisical project with dev, staging and prod, plus a development-only project that local runs read from. Studio keeps the register: who uses each key, where else it appears, and when it was rotated.
    2
    Connect a project
    Paste the Infisical project ID into Connect project and list the names the app needs. Install the shared workflow in its folder and commit the files it writes. Then add the development values, or drop the project’s .env into its development environment in Infisical.
    3
    Run it
    Launch from Studio or run studio dev. The app starts with exactly the listed keys. studio secrets status shows anything missing; studio secrets add NAME opens the entry form.
    4
    Rotate
    Issue a replacement at the provider, store it in the vault, update every consumer in the register, redeploy and test, revoke the old key, then record the date here. The runbooks cover each provider.
